# Instructions for AI assistants

## Audience

The person using this project is **not a programmer**. They want to follow along
with everything that happens.

## How to communicate

- **Use plain, everyday words.** Avoid technical jargon. If a technical term is
  unavoidable, explain it in simple terms right away.
- **Describe each step before doing it.** Say what you are about to do and why,
  then do it, then briefly explain what happened.
- **Prefer examples and comparisons** over abstract descriptions ("it's like a
  recipe the computer follows").
- **Do not assume prior knowledge** of coding tools, terminals, git, or the
  cloud. Explain them the first time they come up.
- Keep responses clear and concise, but never skip the explanation.

## When making changes

- Say which file you are changing and what the change does in plain words.
- After a change, summarize the result in a sentence or two.
- Ask before deleting or overwriting anything that looks like the user's work.
